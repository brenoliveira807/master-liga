# 🏆 Master Liga - Registros de Temporadas

Projeto completo com registros detalhados das temporadas de futebol do **Corinthians**, **Brasil** e **Uruguai**.

## 📁 Estrutura do Projeto

```
master-liga/
├── registros_2028.html      ← Temporada 2028 (47 jogos)
├── registros_2029.html      ← Temporada 2029 (10 jogos)
├── registros_2028.md        ← Documentação da temporada 2028
├── registros_2029.md        ← Documentação da temporada 2029
├── globals.css              ← Reset e fontes Google Fonts
├── styleguide.css           ← Variáveis de tema
├── style.css                ← Estilos dos componentes
└── escudos/                 ← 400+ logos de clubes
```

## 🎯 Principais Funcionalidades

### Temporada 2028
- **Corinthians**: Campeoníssimo histórico!
  - Brasileirão 🏆, Libertadores 🏆, Copa do Brasil 🏆, Copa Intercontinental 🏆
  - 35 jogos · 31 vitórias · 3 empates · 1 derrota
  
### Temporada 2029
- **Corinthians**: Florida Cup e Brasileirão
  - Florida Cup 🏆
  - 10 jogos · 8 vitórias · 2 empates · 0 derrotas

## 🎨 Recursos Técnicos

- ✅ **Estrutura responsiva** com `.matches-row`
- ✅ **Google Fonts** - Titillium Web completa (200-900)
- ✅ **Hover suave** com transição de 600ms e easing personalizado
- ✅ **Acordeão funcional** em cada jogo
- ✅ **Escudos profissionais** de todos os clubes
- ✅ **Design moderno** com paleta escura

## 🚀 Visualização

Abra diretamente no navegador:

- [`registros_2028.html`](./registros_2028.html) - Temporada 2028
- [`registros_2029.html`](./registros_2029.html) - Temporada 2029

## 📝 Como Usar

1. Abra `registros_2028.html` ou `registros_2029.html` no navegador
2. Clique em qualquer jogo para abrir o acordeão com resumos
3. Passe o mouse sobre as linhas para ver o efeito hover (600ms)
4. Explore os escudos de todos os times!

## 🛠️ Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Flexbox, Grid, Transitions, @property
- **Google Fonts** - Titillium Web (familia completa 200-900)
- **JavaScript Vanilla** - Lógica do acordeão
